# Welcome to My First Scraper Ds
***

## Task
Scraping GitHub's trending repositories page and extract data from HTML. The task involves navigating through HTML structure to collect the top 25 trending repositories with their developer names, repository names, and star counts.


## Description

Request: Fetch the GitHub trending page using the 'requests' library.
Extract: Parse HTML using BeautifulSoup to locate all repository elements
Transform: Extract developer names, repository names, and star counts from each repository element, store them in lists, and convert to a pandas DataFrame.
Format: Export to CSV format using pandas built-in method

## Installation
clone the repository.
On terminal run pip install -r requirements.txt

## Usage
Run the project using the command:
python my_first_scraper.py
